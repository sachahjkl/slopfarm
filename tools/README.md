# Outils de développement

Ce dossier conserve les outils intermédiaires utilisés pour construire et contrôler le jeu.

- La simulation produit la forêt dense avec une grille procédurale déterministe.
- `capture-preview.sh` attend le chargement du jeu avant de produire une capture Firefox.

Les scripts Blender restent dans `scripts/blender/` car le flake Nix les utilise directement.
