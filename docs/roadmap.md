# Feuille de route

Chaque étape livre une boucle jouable complète avant d’ajouter la suivante.

## Étape 0 — Socle

- [x] Créer le projet TypeScript, Vite, Three.js et pnpm.
- [x] Ajouter le flake, les contrôles et les hooks.
- [x] Afficher une scène WebGPU pseudo-isométrique.
- [x] Déplacer le personnage et couper des arbres.

## Étape 1 — Première boucle

- [ ] Faire apparaître trois bûches par arbre.
- [ ] Attirer les bûches vers le joueur.
- [ ] Construire la pile dorsale instanciée.
- [ ] Ajouter une zone de vente avec transfert objet par objet.
- [ ] Ajouter une zone d’amélioration de la hache.
- [ ] Sauvegarder l’économie locale.

Critère : le joueur récolte, vend et améliore sa hache sans menu.

## Étape 2 — Base vivante

- [ ] Ajouter les niveaux visuels de l’atelier.
- [ ] Ajouter une capacité de sac et une pile instable.
- [ ] Ajouter un employé transporteur.
- [ ] Ajouter les sons, vibrations et particules.

Critère : trois améliorations changent visiblement le monde.

## Étape 3 — Pression

- [ ] Ajouter le sanglier et son attaque annoncée.
- [ ] Ajouter la santé et la perte partielle de cargaison.
- [ ] Ajouter la hache à zone d’effet.
- [ ] Ajouter le cristal rare.

Critère : le joueur choisit entre une récolte sûre et une récolte rentable.

## Étape 4 — Expansion

- [ ] Ajouter le pont réparable.
- [ ] Ajouter le biome rocheux.
- [ ] Diffuser les zones et leurs ressources.
- [ ] Mesurer les performances sur trois appareils Android.

Critère : dix minutes de progression contiennent deux révélations visuelles majeures.

## Étape 5 — Version large

- [ ] Ajouter les arbres de données pour les biomes et améliorations.
- [ ] Ajouter les outils internes de placement et d’équilibrage.
- [ ] Ajouter les tests Playwright sur appareils ciblés.
- [ ] Ajouter la télémétrie locale de session avec consentement.
- [ ] Définir le modèle commercial avant tout service distant.

Critère : l’équipe ajoute un biome sans modifier le moteur principal.
